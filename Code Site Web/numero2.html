Deuxième partie : Réalisation des requètes SQL

Il nous est demandé ici de réaliser une liste de requêtes. Celles-ci se séparerons en 5 point principaux avec 10 sous catégories dans la première

Numero 1

A)

Ici, nous désirons connaitre les clients parisiens de la base de données et ce en les triant dans l’ordre alphabétique.

Pour cela il nous faut définir les données qui seront affichées :

  • Le nom de la société (Cli.Societe)
  • Le contact (Cli.Contact)
  • Le numéro de téléphone (Cli.Tel)
  • L’adresse mail (Cli.MailCli)
  • La ville (Cli.Ville)

En regardant la base de données, nous voyons que toutes ces données se trouve dans une seule [Clientele].

Il nous est seulement demandé que le client doit être situé à Paris, on peut simplement vérifier en regardant Cli.Ville dans la table [Clientele].

Cette requête se présentera sous cette forme :

SELECT

Cli.Societe,

Cli.Contact,

Cli.Tel,

Cli.MailCli AS Mail,

Cli.Ville

FROM

Clientele AS Cli

WHERE

Cli.Ville LIKE "*Paris*"

ORDER BY

Cli.Societe;

La requête renverra :

B)

Nous cherchons à afficher les produits venants des Etats-Unis coutant moins de 25€.

Pour cela, on affiche :

  • Son nom (Pr.NomProd)
  • Son prix (Pr.CoutAchat)
  • Le fournisseur (F.Societe)
  • La ville du fournisseur (F.Ville)

Toutes ces différentes données sont séparées entre les tables [Fournisseur] et [Produit], il sera donc nécessaire de lier ces 2 tables à condition que :

  • F.NoFour = Pr.NoFour

Maintenant, nous devons vérifier que le fournisseur vienne bien des États-Unis et que le prix de l’article est inferieur à 25€, cela peut se vérifier en regardant les attributs F.NoPays et Pr.CoutAchat.

Mais, si l’on résonne comme cela, nous devons connaitre le numéro de chaque pays et cela serai vraiment inconfortable.

Pour pallier ce problème, nous pouvons lier les tables [Pays] et [Fournisseur] pour :

  • Pa.NoPays = F.NoPays

Et regarder Pa.PaysFR à la place de F.NoPays. (Nous choisissons Pa.PaysFR au lieu de Pa.PaysEN pour plus de confort étant donné que ce travail est en français)

Cette requête se présentera sous cette forme :

SELECT

Pr.NomProd,

Pr.CoutAchat,

F.Societe,

F.Ville

FROM

Produit AS Pr,

Fournisseur AS F,

Pays AS Pa

WHERE

F.NoFour = Pr.NoFour

AND Pa.NoPays = F.NoPays

AND Pr.CoutAchat < 25

Pa.PaysFR LIKE "*Etats-Unis*"

ORDER BY

Pr.NomProd,

Pr.NoFour;

La requête renverra :

C)

Il nous est demandé d’afficher les produits de catégories viandes ou poisson coutant plus de 50€.

Pour cela, nous devrions afficher :

  • Le nom du produit (Pr.NomProd)
  • Son prix (Pr.CoutAchat)
  • Sa catégorie (Cat.NomCateg)
  • Son fournisseur (F.Societe)
  • Son pays de provenance (Pa.PaysFR)

Pour cela il nous faut lier les tables [Pays], [Fournisseur], [Produit] et [Categorie] avec :

  • Pa.NoPays = F.No.Pays
  • F.NoFour = Pr.NoFour
  • Pr.CodeCateg = Cat.CodeCateg

On choisira d’afficher uniquement les produits pour lesquels Cat.NomCateg est égal à Viandes ou Poissons et que Pr.CoutAchat est supérieur à 50€

On réalise la requête avec ceci :

SELECT

Pr.NomProd,

Pr.CoutAchat,

Cat.NomCateg,

F.Societe,

Pa.PaysFR

FROM

Pays AS Pa,

Fournisseur AS F,

Produit AS Pr,

Categorie AS Cat

WHERE

Pa.NoPays = F.NoPays

AND F.NoFour = Pr.NoFour

AND Pr.CodeCateg = Cat.CodeCateg

AND Pr.CoutAchat > 50

AND (Cat.NomCateg LIKE "*Viandes*"

OR Cat.NomCateg LIKE "*Poissons*")

ORDER BY

Pr.NomProd,

Cat.NomCateg,

F.Societe;

La requête renverra :

D)

Nous devons ici afficher les fournisseurs qui vendent de la viande ou du poisson.

Pour cela, il faudrait afficher :

  • Le nom de la société (F.Societe)
  • Le contact (F.Contact)
  • Le numéro de téléphone (F.Tel)
  • La catégorie du produit (Cat.NomCateg)

Il faut ensuite lier les tables [Produit], [Catégorie] et [Fournisseur] de sorte que :

  • Pr.CodeCateg = Cat.CodeCateg
  • Pr.NoFour = F.NoFour

Enfin, le plus important, il faut afficher uniquement si le produit fait partie de la catégorie des viandes ou des poissons.

Cette requête se présentera sous cette forme :

SELECT

F.Societe,

F.Contact,

F.Tel,

Cat.NomCateg

FROM

Produit AS Pr,

Categorie AS Cat,

Fournisseur AS F

WHERE

Pr.CodeCateg = Cat.CodeCateg

AND Pr.NoFour = F.NoFour

AND (Cat.NomCateg LIKE "*Viandes*"

OR Cat.NomCateg LIKE "*Poissons*")

ORDER BY

F.Societe;

La requête renverra :

E)

Pour cette requête, il faudra afficher :

  • Le nom des sociétés (F.Societe)
  • Leur contact (F.Contact)
  • Leur numéro de téléphone (F.Tel)

Toutes ces données sont disponibles dans la table [Fournisseur].

Pour définir lorsqu’il faut afficher, il nous faut utiliser 2 sous requêtes :

La première servira à regarder tous les fournisseurs qui vendent de la viande

La deuxième servira à regarder tous les fournisseurs qui vendent du poisson

Il nous suffira alors à regarder tous les fournisseurs qu’il y a en commun entre les 2 tableaux.

Cette requête se présentera sous le forme :

SELECT

F.Societe,

F.Contact,

F.Tel,

FROM

Fournisseur AS F

WHERE

F.NoFour IN (SELECT

Pr.NoFour

FROM

Produit AS Pr,

Categorie AS Cat

WHERE

PR.CodeCateg = CAT.CodeCateg

AND CAT.NomCateg LIKE "*Viande*")

AND F.NoFour IN (SELECT

Pr.NoFour

FROM

Produit AS Pr,

Categorie AS Cat

WHERE

PR.CodeCateg = CAT.CodeCateg

AND CAT.NomCateg LIKE "*Poissons*")

ORDER BY

F.Societe;

La requête renverra :

F)

La tâche qui nous est demandé ici est assez floue.

Mais afin de répondre au mieux à la problématique je vais choisir arbitrairement les données qui devront être sélectionnées, j’ai choisi large afin d’éviter de rater un produit qui pourrait convenir au risque de devoir filtrer un peu.

Nous déciderons d’afficher :

  • Le nom du produit (Pr.NomProd)
  • Sa quantité par unité (Pr.QteParUnit)
  • Son cout d’achat (Pr.CoutAchat)
  • Son fournisseur (F.Societe)
  • Son contact (F.Contact)
  • Leur numéro de téléphone (F.Tel)

Pour afficher ces données, il faudra lier les tables [Produit] et [Fournisseur] tel que :

  • Pr.NoFour = F.NoFour

Afin de vérifier si le produit est conditionné dans du carton ou du verre, nous vérifierons si Pr.QteParUnit contient les textes : « cartons », « boîtes », « verre » ou « pots ».

La requête :

SELECT

Pr.NomProd,

Pr.QteParUnit,

Pr.CoutAchat,

F.Societe,

F.Contact,

F.Tel

FROM

Produit AS Pr,

Fournisseur AS F

WHERE

Pr.NoFour = F.NoFour

AND (Pr.QteParUnit LIKE "*cartons*"

OR Pr.QteParUnit LIKE "*boîtes*"

OR Pr.QteParUnit LIKE "*verre*"

OR Pr.QteParUnit LIKE "*pots*")

ORDER BY

Pr.NomProd,

Pr.CoutAchat,

F.Societe;

La requête renverra :

G)

Pour trouver les commandes de Max Deschamps, il nous faut effectuer une sous requête parcourant tous les clients et affichant le numéro client (Cli.CodeCli) s’ils s’appellent Max Deschamps.

Ensuite, notre requête devra afficher :

  • Le numéro de commande (Com.N° commande)
  • La date de commande (Com.DateCde)
  • Le nom du produit (Pr.NomProd)
  • Sa quantité (D.Quantité)

Nous devrons ensuite lier les tables [Clientele], [Commande], [DetailCommande] et [Produit] aux moyens de :

  • Cli.CodeCli = Com.CodeCli
  • Com.N° Commande = D.N° Commande
  • D.Réf produit = Pr.RefProd

Enfin, pour ne sélectionner que les 3 dernières commandes, nous devons réaliser une autre sous requête qui vérifiera s’il y a ou non 3 commandes plus récentes.

Cette requête affichera donc les commandes ordonnées par numéro de commandes et par date

La requête :

SELECT

Com.[N° commande],

Com.DateCde AS Date de la Commande,

Pr.NomProd AS Produit,

D.Quantité

FROM

Clientele AS Cli,

Commande AS Com,

DetailCommande AS D,

Produit AS Pr

WHERE

Cli.CodeCli = Com.CodeCli

AND Com.[N° commande] = D.[N° commande]

AND D.[Réf produit] = Pr.RefProd

AND Cli.CodeCli LIKE (SELECT

Cli2.CodeCli

FROM

Clientele AS Cli2

WHERE

Cli2.Contact = "Max Deschamps")

AND (SELECT COUNT(*)

FROM

Commande AS Com2

WHERE

Com2.CodeCli = Com.CodeCli

AND (Com2.DateCde > Com.DateCde

OR (Com2.DateCde = Com.DateCde

AND Com2.[N° commande] > Com.[N° commande]))

) < 3

GROUP BY

Com.[N° commande],

Com.DateCde,

Pr.NomProd,

D.Quantité

ORDER BY

Com.DateCde DESC;

La requête renverra :

H)

Afin d’afficher les fournisseurs ne proposant que des desserts, il nous faudra créer une sous requête affichante, au contraire, tous les fournisseurs qui vendent autre chose que des desserts.

On créera cette requête en vérifiant pour chaque produit s’il est dans la catégorie des desserts et on l’affiche son fournisseur si ce n’est pas le cas.

On affichera :

  • Le nom des fournisseurs (F.Societe)
  • Leur contact (F.Contact)
  • Leur numéro (F.Tel)

Il nous faudra vérifier pour chaque fournisseur s’il fait parti ou non du tableau crée par la sous requête.

La requête prendra cette forme :

SELECT

F.Societe,

F.Contact,

F.Tel

FROM

Fournisseur AS F

WHERE

F.NoFour NOT IN (SELECT

F2.NoFour

FROM

Fournisseur AS F2,

Produit AS Pr,

Categorie AS Cat

WHERE

F.NoFour = Pr.NoFour

AND Pr.CodeCateg = Cat.CodeCateg

AND NomCateg NOT LIKE "*dessert*"

)

ORDER BY

F.Societe;

La requête renverra :

I)

Ici, nous recherchons les fournisseurs étrangers ne possédant aucune clé étrangère dans la table [Produit].

Nous allons afficher :

  • Le nom du fournisseur (F.Societe)
  • Son contact (F.Contact)
  • Son numéro (F.Tel)
  • Son pays (P.PaysFR)

Pour cela, il nous faut lier les tables [Fournisseur], [Produit] et [Pays] tel que :

  • Pr.NoFour = F.NoFour
  • F.NoPays = P.NoPays

Il faut aussi préciser que l’usage d’un LEFT JOIN est nécessaire dans ce cas puisqu’il est question de fournisseurs ne possédants pas de produits.

Une telle requête s’écrit de cette manière :

SELECT

F.Societe,

F.Contact,

F.Tel,

Pa.PaysFR

FROM

(Pays AS Pa

INNER JOIN Fournisseur AS F

ON F.NoPays = Pa.NoPays)

LEFT JOIN Produit AS Pr

ON Pr.NoFour = F.NoFour

WHERE

Pr.NoFour IS NULL

AND Pa.PaysFR NOT LIKE "*France*"

ORDER BY

F.Societe,

Pa.PaysFR

La requête renverra :

J)

Même si cette question me parait obscure, je vais partir du principe qu’il nous est demandé d’afficher tous les couples de clients qui peuvent exister dans la base de données parmi ceux qui sont situés à Paris.

J’ai choisi d’afficher les informations par paires :

  • Les noms des clients (Cli1.Societe et Cli2.Societe)
  • Leurs contact (Cli1.Contact et Cli2.Contact)
  • Leur mail (Cli1.MailCli et Cli2.MailCli)
  • Leur numéro de téléphone (Cli1.Tel et Cli2.Tel)

Il nous suffira alors de vérifier, pour chaque client, de vérifier s’il se trouve à Paris pour afficher les couples.

On comparera aussi les codes clients pour éviter les doublons ainsi que des couples déjà affichés, le client de gauche aura toujours un code client plus petit que celui de droite.

Voici le code de la requête :

SELECT

Cli1.Societe,

Cli2.Societe,

Cli1.Contact,

Cli2.Contact,

Cli1.MailCli,

Cli2.MailCli,

Cli1.Tel,

Cli2.Tel

FROM

Clientele AS Cli1,

Clientele AS Cli2

WHERE

Cli1.CodeCli < Cli2.CodeCli

AND Cli1.Ville LIKE "*Paris*"

AND Cli2.Ville LIKE "*Paris*"

ORDER BY

Cli1.Societe;

La requête renverra :

Numero 2

Pour cette requête, il faudra afficher le chiffre d’affaires total que l’entreprise a généré avec les fournisseurs européens.

Pour cela il nous faudra afficher :

  • Le chiffre d’affaires total (CA_fournisseurs_UE)

Et cela au moyen de la fonction SUM qui fera la somme de l’argent gagné pour chaque produit venant des fournisseurs européens.

L’argent gagné par produit sera calculé en multipliant le prix de vente du produit pas la quantité achetée et par sa remise, on arrondira le résultat au moyen de la fonction ROUND qui nous permettra d’arrondir aux centièmes arithmétiques.

Nous devrons lier les tables [Pays], [Fournissseur], [Produit] et [DetailCommande] de sorte que :

  • Pr.RefProd = D.Réf produit
  • F.NoFour = Pr.NoFour
  • Pa.NoPays = F.NoPays

Il nous faudra aussi vérifier si le fournisseur vient d’un pays de l’UE.

Voici la requête :

SELECT

Round(Sum(D.Quantité * CoutAchat * [Remise (%)]), 2)

AS CA_fournisseur_UE

FROM

Pays AS Pa,

Fournisseur AS F,

Produit AS Pr,

DetailCommande AS D

WHERE

Pr.RefProd = D.[Réf produit]

AND F.NoFour = Pr.NoFour

AND Pa.NoPays = F.NoPays

AND Pa.UE LIKE "*Membre*"

La requête renverra :

Numero 3

Pour réaliser cette requête il faudra afficher le chiffre d’affaires total que l’entreprise a généré avec les produits de types desserts ou boissons.

Pour cela il nous faut afficher :

  • L’année (Année)
  • Le chiffre d’affaires total (CA_Categ_dessert_et_boisson)

On fera cela avec SUM qui fera la somme de l’argent gagné pour chaque produit étant dans les catégories desserts ou boissons

Nous devrons lier les tables [Categorie], [Produit], [Commande] et [DetailCommande] de sorte que :

  • Pr.CodeCateg = Cat.CodeCateg
  • Com.N° commande = D.N° commande
  • Pr.RefProd = D.Réf produit

Nous devrons aussi vérifier la catégorie des différents produits et grouper les données pour avoir les données annuelles à l’aide de le fonction YEAR.

La requête se présentera sous la forme :

SELECT

Year(Com.DateCde) AS Année,

Round(Sum(Pr.CoutAchat * D.Quantité * [Remise (%)]), 2)

AS CA_Categ_dessert_et_boisson

FROM

Categorie AS Cat,

Produit AS Pr,

Commande AS Com,

DetailCommande AS D

WHERE

Pr.CodeCateg = Cat.CodeCateg

AND Com.[N° commande] = D.[N° commande]

AND Pr.RefProd = D.[Réf produit]

AND Cat.NomCateg IN ("Dessert", "Boissons")

GROUP BY

Com.DateCde

ORDER BY

Year(Com.DateCde)

La requête renverra :

Numero 5

Afin de réaliser cette requête, il nous faudra afficher :

  • Le nom du client (Cli.Societe)
  • Le nom de son client partenaire (CliP.Societe)
  • Le nombre de commandes que possèdent les 2 clients (NbrCommandes et NbrCommandesPilote)

Il nous faudra aussi lier les tables [Clientele], [Clientele(Pilote)], [Commande] et [Commande(Pilote)] tel que :

  • Cli.CodeCliPart = CliP.CodeCli
  • ComP.CodeCli = CliP.CodeCli
  • Com.CodeCli = Cli.CodeCli

Il nous faudra vérifier que les codes clients soient différent pour éviter les doublons et vérifier que les nombres de commandes soient les mêmes pour les 2 clients

La requête :

SELECT

Cli.Societe,

CliP.Societe AS ClientPilote,

(SELECT COUNT(*) FROM AS Com WHERE Com.CodeCli = Cli.CodeCli)

AS NbrCommandes,

(SELECT COUNT(*) FROM Commande AS ComP

WHERE

ComP.CodeCli = CliP.CodeCli)

AS NbrCommandesPilotes

FROM

Clientele AS Cli,

Clientele AS CliP

WHERE

Cli.CodeCliPart = CliP.CodeCli

AND Cli.CodeCli <> CliP.CodeCli

AND (SELECT

COUNT(*)

FROM

Commande AS Com

WHERE

Com.CodeCli = Cli.CodeCli) = (SELECT

COUNT(*)

FROM

Commande AS ComP

WHERE

ComP.CodeCli = CliP.CodeCli);

ORDER BY

Cli.Societe

CliP.Societe
