Enoncé 1: Lister les produits qui sont situés dans la zone européenne

Interet :

Il serait intéressant de regarder si l’entreprise Kdou est écoresponsable car c’est l’un de ses objectifs finals. Comme Kdou est une entreprise francaise, les produits européens sont donc + avantageux car nécessite - de cout de transport ce qui réduit l'empreinte carbone lié au transport. Cela correspond à l'objectif stratégique de développement durable de l'entreprise.

Requête SQL :

SELECT Pays.PaysFR AS Pays_Fournisseur,prod.Nomprod AS Nom_produit 
FROM (Produit AS prod INNER JOIN Fournisseur AS Four ON prod.Nofour = 
Four.Nofour)INNER JOIN Pays On Four.NoPays = Pays.NoPays  
WHERE UE = "Membre" 
ORDER BY Pays.PaysFR
Conception :

D’abord, il faut faire 2 jointures pour avoir les données entre le pays, le fournisseur, et le produit. Ensuite, il faut filtrer selon les produits européens avec une WHERE Enfin on fait un tri pour faciliter la lecture avec un ORDER BY. On décidera d’afficher le Nom du produit + Le pays d’origine de son fournisseur

Enoncé 2: Lister les produits qui coutent plus de 30 euro

Interet :

Selon moi, une requête qui serait intéressante serai celle qui donne tous les produits coutant plus de 30€, cette requête pourrait permettre à l’entreprise de réfléchir çà son offre commerciale, elle pourrait voir les produits les plus intéressants à vendre pour un meilleur chiffre d’affaires. On groupera les produits par leurs prix et les organiserons dans l’ordre décroissant. On y affichera le prix du produit(Pr.CoutAchat), son nom(Pr.NomProd), sa catégorie(Cat.NomCateg), son fournisseur(F.Societe) ainsi que son contact(F.Contact) et son numéro de téléphone(F.Tel). Pour cela, on liera les tables [Produit], [Categorie] et [Fournisseur] tel que Pr.NoFour = F.NoFour et Pr.CodeCateg = Cat.CodeCateg.

Requête SQL :

SELECT Pr.CoutAchat, Pr.NomProd, Cat.NomCateg,
F.Societe, F.Contact, F.Tel
FROM Produit AS Pr, Categorie AS Cat, Fournisseur AS F
WHERE Pr.CoutAchat > 30 AND Pr.NoFour = F.NoFour AND Pr.CodeCateg = Cat.CodeCateg
ORDER BY Pr.CoutAchat DESC;

Enoncé 3: renvoyer les chiffres d’affaires par pays fournisseur

Interet :

Cette requête permet d'afficher, pour chaque pays fournisseur, le montant total des frais de port et le nombre de commandes associées. Pour KDou, c'est un outil concret pour optimiser notre budget logistique. En classant les résultats du plus cher au moins cher, on repère directement les zones qui pèsent trop lourd dans nos dépenses. Cela nous donne des chiffres précis pour réajuster nos choix d'approvisionnement ou négocier de meilleurs tarifs avec nos transporteurs.

Requête SQL :

SELECT Sub.PaysFR AS Pays_Fournisseur, COUNT(Sub.[N° commande]) AS Nb_Commandes, SUM(Sub.Port) AS Total_Frais_Port
FROM (SELECT DISTINCT Pa.PaysFR, C.[N° commande], C.Port
    FROM Pays AS Pa, Fournisseur AS F, Produit AS Pr, DetailCommande AS DC, Commande AS C
WHERE Pa.NoPays = F.NoPays
        AND F.NoFour = Pr.NoFour
        AND Pr.RefProd = DC.[Réf produit]
        AND DC.[N° commande] = C.[N° commande]) AS Sub
GROUP BY Sub.PaysFR
ORDER BY SUM(Sub.Port) DESC;
